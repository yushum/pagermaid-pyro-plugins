# linkcopy

按 Telegram 消息链接复制文字和媒体。使用运行 PagerMaid 的账号读取来源，无需额外机器人或 API 密钥。

## 使用

在目标聊天发送：

```text
,linkcopy https://t.me/example/123
,linkcopy https://t.me/c/1234567890/123
```

也可以回复一条包含消息链接的消息，发送 `,linkcopy`。支持隐藏超链接；被回复的消息必须恰好包含一个有效的 Telegram 消息链接。

- **文字**：将命令消息编辑为原文，保留 Telegram 文本实体。
- **媒体**：支持图片、视频、文件、音频、语音、动图、贴纸和视频圆消息。发送成功后自动删除命令及进度消息。
- **相册**：默认复制整个相册，保留顺序、配文和文本实体。添加 `--single` 或使用带 `?single` 的链接，只复制选中的一项。
- **封面**：复用视频时保留独立的视频封面和播放起点；重新上传时下载并携带来源缩略图及视频封面，相册同样支持。来源没有提供封面或缩略图时，不会自动生成。
- **发送位置**：发送到当前聊天和当前 Topic。显式提供链接时保留命令的回复关系；通过回复获取链接时，保留被回复的消息。

```text
,linkcopy https://t.me/example/123 --single
```

支持公开链接、`t.me/c/...` 私有链接、包含 Topic ID 的链接、`t.me/s/...` 预览链接，以及 `tg://resolve?...&post=...`、`tg://privatepost?...&post=...`。带 `?comment=...` 的链接会读取对应讨论组的评论。

## 批量复制

提供起始链接和结束链接，按消息 ID 顺序复制，包含两端：

```text
,linkcopy https://t.me/example/100 https://t.me/example/178
,linkcopy https://t.me/example/100 到 https://t.me/example/178
```

- 两个链接必须来自同一频道或群组；结束消息 ID 不小于起始消息 ID，单次最多处理 1000 个消息 ID。两个链接之间也可以使用 `-`。
- 按整个聊天的消息 ID 范围读取，不会按 Topic 筛选。两个链接需要使用相同的聊天标识，不能混用用户名链接与 `t.me/c/...` 链接。评论链接仅支持单条复制。
- 已删除、缺失、服务消息和不支持的消息类型会跳过，并计入统计。来源无法访问、相册不完整、读取或发送出错时，任务中止。
- 同一个相册只发送一次；相册跨越区间边界时，只复制区间内的成员。添加 `--single` 可逐条发送。
- 每次发送一条消息或一个相册后间隔至少 1 秒。同一个目标聊天同时只允许一个批量任务。
- 进度消息约每 3 秒更新，显示已处理数量和百分比、已发送数量及跳过数量。下载或上传期间继续显示批量进度，同时显示当前文件的传输状态。
- **全部处理完成后自动删除进度消息**。如果 Telegram 拒绝删除，会提示手动删除；内容不会因此重复发送。

发送以下命令可请求停止：

```text
,linkcopy cancel
```

当前下载或发送完成后停止，保留统计和下一条未处理消息的链接。使用该链接与原结束链接可以继续复制。

读取、网络或发送错误会中止任务，并保留统计和出错位置。发生错误的消息或相册可能已经送达，请检查目标聊天后选择继续复制的位置。任务进度保存在内存中，插件重载或进程重启后不会自动恢复。

## 媒体传输

优先复用 Telegram 文件引用。收到明确的内容保护或文件引用错误后，下载媒体、缩略图和视频封面，再重新上传。相册会在所有成员下载完成后整组发送。

大小已知且至少为 16 MiB 的媒体，在支持的 Pyrogram 版本中使用最多 4 路并行下载，每块 1 MiB。其他情况使用 Pyrogram 原生下载器；遇到 CDN 重定向时，清理已有分块文件，再交由原生下载器处理。

原生下载、并行下载、单条上传和相册逐项上传均显示文件传输进度，包括百分比、已传输大小、平均速度和预计剩余时间；传输通知约每 3 秒更新。小文件可能在下一次更新前完成。

- 下载完成后检查已知文件大小；并行下载还会检查每块长度。
- 插件内同时只进行一个并行下载，不会并行复制整批消息。实际速度取决于 Telegram 限速、网络、磁盘及加密性能。
- 临时文件存放在当前工作目录的 `.work/linkcopy/`，成功、失败或任务取消后均清理。
- 短期限流会等待后重试；网络超时不会自动重发内容，长期限流会终止任务。失败时保留命令并显示原因。

## 读取范围与权限

当前账号需要能够读取来源。私有频道或群组通常需要提前加入；插件不会自动加入聊天，无法读取已删除或无权访问的消息。Telegram 的服务端限制仍可能阻止下载或重新上传。

暂不支持服务消息、投票、位置、联系人和付费媒体。不复制消息按钮、转发来源、浏览量及互动数据。普通粘贴链接不会触发复制，需要使用 `,linkcopy` 命令。命令仅对当前账号开放，不接受 sudo 用户的请求。
